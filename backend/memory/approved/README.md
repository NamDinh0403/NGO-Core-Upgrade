# Approved reusable patterns

This directory holds patterns that have passed validation, regression replay, and
developer approval. Records here use `schemas/fix-pattern.schema.json` /
`schemas/error-pattern.schema.json` with `status: approved`.

Approved patterns are guidance only and remain below the decompiled installed DLL
in the authority hierarchy (`config/knowledge-priority.yaml`).

Subfolders: `fix-patterns/`, `error-patterns/`, `upgrade-rules/`.
